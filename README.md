# mPrimal

Artefact for Sections 4, 5 and 6 of the paper _"Refined Modelling of the Primal Attack, and Variants against Module-LWE"_, Paola de Perthuis and Filip Trenkić.

(Builds on the codebase of [mBKZ](https://github.com/lducas/mBKZ))

## Contents

- `primal_MLWE.py` contains the code for generating (normal form, primal formulation) Module-LWE instances
- `mhkz_profile.py` generates experimental mHKZ profiles for use in the Module-BKZ simulator (Section 4)
- `mBKZsim.py` contains the Module-BKZ simulator (Section 4), the GSA and mGSA for MLWE (Section 5), the success probability models for the module primal attack, standard primal attack, and l-embedding primal attack (Sections 5-6)
- `exp_successprob.py` contains the code for running experiments (Sections 5-6)

## Installation

1. Make sure packages `gmp`, `mpfr`, `python`, `libtool`, `qd` are installed.
2. Build [g6k](https://github.com/fplll/g6k):
    ```
    git submodule add "https://github.com/fplll/g6k"
    cd g6k
    PYTHON=python3 ./bootstrap.sh
    cd ..
    ```
3. Add `scipy` to the virtual environment: `source g6k/activate; pip install scipy`.
4. To run the python scripts, make sure to activate the virutal environment each time.

## Reproducing experiments

### Section 4
- Ensure `data/exp_mHKZ_profiles.csv` exists (generated by `mhkz_profile.py`)
- Ensure all data in `data/profiles_d160_beta64` exists (taken from [mBKZ](https://github.com/lducas/mBKZ/tree/main/data_paper/profiles_d160_beta64))
- Run `pred_profiles.py`.
- The generated data (experimental, mGSA profiles, and simulated profiles) are found in `data/profiles_d160_beta64/sim_c1.csv` and similarly `sim_c3, sim_c4, sim_c15, sim_c16`.

### Section 5

The experiments are designed to run in parallel, utilising the full available resources of a compute cluster using the `slurm` scheduler.

To run all experiments from the paper:

```
sbatch mPrimal_params1.sh
sbatch mPrimal_params2.sh
sbatch mPrimal_params3.sh
sbatch mPrimal_params4.sh
sbatch mPrimal_params1_prog.sh
```

To collect all data, run `collect_data_mPrimal.py`, which generates `data/mPrimal240/c3/bkz_all.csv`, and same for `c5`, `c7`, `c8`.

### Section 6

To run all experiments:

```
sbatch exp_l_embeddings_fpylll.sh
sbatch exp_l_embeddings_g6k.sh
```

To collect all data, run `collect_data_lembed.py`, which generates `data/lembed/fpylll/lembed_all.csv`, and `.../g6k/lembed_all.csv`
